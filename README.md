## About

I am a backend-focused software developer building production systems with a strong emphasis on security, reliability, and clean architecture. My public work centers on Node.js, TypeScript, PostgreSQL, Redis, Docker, and full-stack delivery, with a clear bias toward systems that solve real problems instead of collecting dust in a repo graveyard.

I have spent about 1.5 years building and shipping projects across authentication, automation, and product engineering. My strongest work sits around REST APIs, authentication flows, session management, queue-driven pipelines, and backend architecture decisions that make software easier to maintain and harder to break.

I care about architecture because shortcuts rot. I care about auth because weak security is expensive. I care about APIs because every messy endpoint becomes somebody else's headache. I like building things that are useful, boring in the best way, and ready for production pressure.
